Release plan

  1. Now

    Development builds

    Internal installer images are built and tested on every change: start-up, performance and privacy checks.

  2. Next

    SelvaraOS 1.0 Canopy

    The first public release, for PCs with Intel or AMD processors.

  3. Later

    Apple Silicon

    A version for virtual machines on Apple Silicon Macs, then native support for M1 and M2 Macs.

What you'll need

Expected requirements for the first release.

Processor
64-bit Intel or AMD
Memory
4 GB or more
Storage
25 GB free
To install
A USB stick, 8 GB
