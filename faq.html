Questions and answers

Is SelvaraOS free?

Yes. It is free to download and use, and everything we write is free software under the GPL-3.0 licence.

Do I need to know Linux?

No. SelvaraOS is designed for people who have never used Linux. Everyday tasks never need a terminal.

Will it run on my old computer?

If it has a 64-bit Intel or AMD processor and at least 4 GB of memory, it is a computer we build for. We measure performance on a machine like that on every build.

Is it a copy of macOS?

No. The design and the code are our own. If you come from a Mac, the layout and the shortcuts will feel familiar, which makes switching easier.

What is it built on?

Debian 13, one of the most stable Linux distributions, and the KWin compositor. The desktop, the settings and the system apps are written by us.

Does it collect any data?

No. There is no telemetry, and nothing connects to the internet unless you ask. An automated test checks this on every build.

Can I install the apps I use?

Yes. Thousands of apps are available from Flathub and Debian, and the installer lets you pick popular apps and your browser before you start.

Can I keep Windows next to it?

Yes. The installer will let you install SelvaraOS alongside the system you already have.

When will it be released?

When it is ready. Join the Discord server or follow the project on GitHub to hear first.

Will it run on a Mac?

A version for virtual machines on Apple Silicon Macs is planned after 1.0, followed by native support for M1 and M2 Macs.
